# Template 3214 - Search Results

## O que é este template?

Este é um **Elementor Loop Item** usado para exibir resultados de pesquisa no WordPress. É um template especificamente criado para formatar como cada item de resultado aparece quando usuários fazem pesquisas no site.

## Tipo de Template

- **Tipo:** Elementor Loop Item
- **ID:** 3214
- **Nome:** Search Results
- **Status:** Publicado

## Para que serve?

Este template define a estrutura visual de cada resultado individual em uma página de pesquisa. Quando alguém pesquisa algo no site, este template controla:

- Como o título do post aparece
- Como a imagem destacada é exibida
- Como o resumo/excerpt é formatado
- Como os metadados (data, autor, etc.) são mostrados
- O layout geral de cada item de resultado

## Como é aplicado?

O template é usado automaticamente pelo Elementor quando:
1. Uma pesquisa é realizada no site
2. O sistema precisa exibir múltiplos resultados
3. Cada resultado individual usa este template para manter consistência visual

## Arquivos Incluídos

- `template-data-complete.json` - Dados completos do WordPress
- `metadata.json` - Metadados básicos do template
- `elementor-structure.json` - Estrutura do Elementor para edição
- `template-content.html` - HTML renderizado (se disponível)
- `download.py` - Script para baixar/atualizar o template

## Estrutura Elementor

Este template contém a estrutura de elementos Elementor que define:
- Containers e seções
- Widgets utilizados
- Configurações de estilo
- Responsividade
- Configurações dinâmicas para conteúdo

## Uso Local

Este pacote permite editar o template localmente e depois fazer upload das modificações de volta para o WordPress, mantendo controle de versão e backup das alterações.
