Plano de Discagem: O Coração da Roteirização Telefônica

O plano de discagem é o cérebro por trás do direcionamento inteligente das chamadas na sua empresa. Com ele, você define fluxos personalizados para cada número de entrada, garantindo que cada ligação siga o melhor caminho: seja para um menu de atendimento, uma fila, um ramal específico ou até mesmo para um anúncio ou caixa postal.

Como funciona um plano de discagem?

Imagine que cada ligação recebida é como um visitante em um aeroporto: o plano de discagem é o painel que direciona cada um para o portão certo, de acordo com o horário, o motivo da chamada e as opções escolhidas pelo cliente.

  • Horários e condições: Defina regras para dias úteis, finais de semana, feriados e horários especiais.
  • Menus (URA): Ofereça opções para o cliente escolher o setor desejado (ex: 1- Comercial, 2- Suporte, 3- Financeiro).
  • Filas de espera: Direcione chamadas para grupos de atendimento, garantindo agilidade e organização.
  • Anúncios e saudações: Programe mensagens personalizadas para diferentes situações.
  • Caixa postal e redirecionamento: Encaminhe ligações não atendidas para a caixa postal ou para outro número.

Exemplo prático de fluxo de discagem

1. Ligação recebida no número principal
→ Condição de horário: Se for horário comercial, toca um anúncio de boas-vindas e direciona para a URA.
→ URA: Cliente escolhe 1 (Comercial), 2 (Suporte) ou 3 (Financeiro).
→ Fila: Se escolher 1, vai para a fila Comercial; se não escolher, vai para a fila padrão.
→ Falha ou não atendimento: Se ninguém atender, a chamada pode ser encaminhada automaticamente para a caixa postal, para outro número fixo ou celular (por exemplo, o celular do responsável pelo setor), ou até mesmo gerar uma notificação instantânea no WhatsApp ou Telegram informando sobre a mensagem de voz recebida na caixa postal. Assim, você nunca perde uma oportunidade de contato e garante agilidade no retorno ao cliente.
